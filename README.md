# ProblemePbInfo
#### Romanian: 
Rezolvarile personale ale problemelor de pe site-ul https://www.pbinfo.ro/. Proiectul contine deocamdata mare parte din probleme de clasa a 9-a si de clasa a 10-a unele rezolvate cu limbajul C, altele cu C++.

#### English:
Personal solutions to the problems from the website https://www.pbinfo.ro/. The project currently contains most of the problems for 9th and 10th grade, some solved using the C language, others with C++."
